# [ARR] Adaptive Motion Scaling with Phase-and-Gaze Awareness for Laparoscopic Robotic Teleoperation

## Overview

The paper presents an adaptive motion scaling framework for laparoscopic robotic teleoperation. It combines real-time surgical phase recognition with robot kinematics and gaze features to adjust motion scaling during task execution. User-specific parameters are tuned through Bayesian optimization, with the aim of reducing clutching while maintaining precision and responsiveness.
